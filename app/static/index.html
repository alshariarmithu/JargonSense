Why this stage exists

Senti4SD contains almost none of the vocabulary this project is about. fatal 0×, hang 0×, abort 0×, kill 3× in 3,031 posts. Four separate analyses agree. So the claim is tested on 60 sentences written for the purpose: 40 harsh-but-neutral, 20 genuine complaints, 10 minimal pairs.
